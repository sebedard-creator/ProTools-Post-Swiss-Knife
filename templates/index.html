📖 Guide d'utilisation

📍 MARKERS
Exporte les markers d'une session Pro Tools en PDF compact (Timecode + Nom du marker).
Dans Pro Tools : File → Export → Session Text, tout désélectionner sauf "Include Markers".
Entrée : .txt  |  Sortie : .pdf
📄 SPOTTING
Crée un PDF listant tous les clips par track avec timecodes IN/OUT, durée, nom du clip et état muté/non-muté. Les clips mutés sont identifiés par "SI VOUS AVEZ LE TEMPS".
Dans Pro Tools : File → Export → Session Text, tout désélectionner sauf "Include Track EDLs".
Entrée : .txt  |  Sortie : .pdf
📊 ADR CHARACTER ORDER
Crée un fichier Excel organisé par personnage. Chaque section affiche le nom suivi du nombre de lignes (ex: VALÉRIE - Catherine Chabot - 16 Lignes), puis les cues avec timecodes, durée, texte et commentaire. Surlignage jaune automatique pour les mots-clés VALIDER, TBC ou TBW.
Dans Pro Tools : File → Export → Session Text, tout désélectionner sauf "Include Track EDLs".
Entrée : .txt  |  Sortie : _CHARACTER_ORDER.xlsx
🕐 ADR TC ORDER
Crée un fichier Excel avec tous les cues de tous les personnages dans une liste unique triée par timecode. Chaque ligne inclut un numéro séquentiel par personnage (ex: VAL001, VAL002…), le nom du personnage, les timecodes, la durée, le texte et le commentaire.
Dans Pro Tools : File → Export → Session Text, tout désélectionner sauf "Include Track EDLs".
Entrée : .txt  |  Sortie : _TC_ORDER.xlsx
🎙️ ADR RECORDING
Génère un ZIP avec deux PDFs par personnage : feuille ACTEUR (grand texte) et feuille TECHNICIEN (avec TAKE SELECT et TAKE ALT). Affiche la convocation tirée du champ Comments de la track. Le texte entre parenthèses est mis en italique. Une flèche ↓ indique quand le cue suivant débute dans les 2 secondes.
Dans Pro Tools : File → Export → Session Text, tout désélectionner sauf "Include Track EDLs". Inscrire la convocation dans le champ Comments de chaque track.
Entrée : .txt  |  Sortie : .zip
🔄 CSV VERS EDL
Crée un fichier EDL à partir d'un CSV exporté de la template Excel pour les notes de playback.
Entrée : .csv  |  Sortie : .edl
📄 CSV VERS PDF (TC ORDER)
Convertit un CSV de notes en PDF trié par timecode. Trois colonnes : TC IN, NOTE (nom de la piste cochée) et COMMENTAIRE. Une ligne CSV avec plusieurs pistes cochées génère plusieurs entrées dans le PDF.
Entrée : .csv  |  Sortie : .pdf
🚀 CSV VERS AAF
Conversion directe CSV → AAF en une seule étape (combine CSV VERS EDL et EDL VERS AAF). Choisir le mode Production ou Conception — ajouté en suffixe au nom du fichier.
Entrée : .csv  |  Sortie : _production.aaf ou _conception.aaf
📍 XLS VERS AAF MARKERS
Génère une piste de marqueurs (Memory Locations) à 23.976 fps à partir d'un fichier Excel. Recherche automatiquement la colonne TC IN et fusionne Description et Notes particulières.
Entrée : .xls, .xlsx  |  Sortie : .aaf
